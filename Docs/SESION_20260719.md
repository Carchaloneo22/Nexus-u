## 4. MECÁNICA DE JUEGO

**Click-to-order** (no drag & drop):
1. Jugador clickea dispositivos en orden: MÓDEM → ROUTER → PC
2. Cada click → `AddItem("Modem")` → se resalta el device
3. `TXT_Sequence` se actualiza mostrando la secuencia
4. Botón **VERIFICAR** → `CheckSequence()`:
   - ✅ Correcto → `OnPuzzleCompleted`, feedback verde
   - ❌ Incorrecto → feedback rojo con error
5. Botón **REINICIAR** → `ResetGame()`, limpia todo
6. Botón **CERRAR** → cierra widget sin verificar

### Alternativas visuales consideradas (pendiente decisión):
- **A) Básica** — 3 botones tipo tarjeta, solo texto con flechas `→`
- **B) Con cables visuales** — líneas (Image rotada) entre devices al clickear
- **C) Drag & drop real** — arrastrar cables entre puertos (mucho más complejo)

## 5. EVENT GRAPH (nodos en BP)

```
Event Construct
  ├── Set TXT_Sequence = "Haz clic en los dispositivos..."
  ├── Set TXT_Resultado = ""
  └── (resaltados a gris)

OnClicked (BTN_Modem)     → AddItem("Modem")
OnClicked (BTN_Router)    → AddItem("Router")
OnClicked (BTN_PC)        → AddItem("PC")

OnClicked (BTN_Verificar)
  ├── CheckSequence → Branch
  │   ├── True  → TXT_Resultado = "✅ Correcto!" (verde)
  │   │          → Delay 1.5s → OnPuzzleCompleted
  │   └── False → TXT_Resultado = "❌ Orden incorrecto" (rojo)

OnClicked (BTN_Reiniciar)
  ├── ResetGame()
  ├── TXT_Sequence = ""
  └── TXT_Resultado = ""

OnClicked (BTN_Cerrar)
  └── Remove from Parent
```
